# Словарь терминов

Термины используются строго в этих значениях, без синонимов. Если в тексте
скилла нужно сказать что-то из правого столбца, используется термин из
левого, а не синоним.

**Снимок, архив, дамп и бэкап это разные вещи.** Архив это то, что отдал
хостинг; дамп это выгрузка базы; снимок это принятая пара «файлы плюс дамп», из
которой разворачивают; бэкап это регулярный набор на работающей площадке.

| Термин | Определение | Запрещённые синонимы |
|---|---|---|
| конвейер | вся последовательность из восьми фаз, ведущая от заражённого хостинга к работающему сайту на VPS | процесс, пайплайн, воркфлоу |
| фаза | один из восьми пронумерованных этапов конвейера со своей страницей в `references/` | этап, шаг, стадия |
| ворота | обязательный проверяемый критерий выхода из фазы, без прохождения которого следующая фаза не начинается | гейт, чекпоинт, критерий |
| прорез | проверка внешнего поведения системы целиком в точке, где отказ уже случался: слепой прогон агента, живой пробник против запрета | шов, проверка, тест |
| снимок | копия файлов сайта и дампа базы на конкретный момент времени, источник для восстановления | слепок, копия сайта |
| точка отката | прежняя живая площадка вместе с записанным состоянием записей домена, к которым возвращаются при неудаче переключения | rollback, откатная точка |
| переключение | момент смены обслуживающего сервера для домена (DNS или делегирование) | катофер, cutover, релиз |
| докрут | корень сайта: каталог, от которого веб-сервер считает пути запросов | документ-рут, document root, корень |
| ядро | часть конвейера, не зависящая от конкретной CMS: стек, сеть, лимиты, прокси | база, платформа, инфраструктура |
| адаптер | тонкий слой конфигурации и скриптов, специфичный для конкретной CMS, поверх ядра | плагин, коннектор, модуль |
| трассер | набор живых пробников, доказывающий, что запреты и изоляция работают на поднятом стеке, а не только описаны в конфигурации | тестер, чекер, сканер |
| смоук | внешняя проверка сайта чёрным ящиком по настоящему имени хоста, со сравнением тел ответов | прогон, проверка доступности |
| профиль площадки | файл с параметрами конкретного сайта (слаг, домен, версии), из которого рендерятся шаблоны | конфиг сайта, инпут, манифест сайта |
