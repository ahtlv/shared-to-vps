# shared-to-vps

Конвейер переезда сайта с заражённого или развалившегося общего хостинга на
изолированный VPS. Восемь фаз, каждая со своими воротами. Пропускать фазу или
принимать ворота на слово запрещено.

## Определение состояния и точка входа

| Состояние | Признак | Точка входа |
|---|---|---|
| Аккаунт скомпрометирован, снимок ещё не снят | вебшеллы, посторонние процессы, запись в чужие площадки на аккаунте | [Ф0 Триаж](references/00-triage.md) |
| Снимок уже есть, чистота не доказана | архив или дамп базы на руках, происхождение и чистота не подтверждены | [Ф1 Архив](references/10-archive.md) — ворота Ф0 при этом достраиваются задним числом, не пропускаются |
| Снимок чист, стека ещё нет | чистота доказана, площадка ещё не разворачивалась | [Ф2 Стек](references/20-stack.md) |
| Стек поднят, сайт ещё не восстановлен | ядро развёрнуто, контента и конфига сайта в нём нет | [Ф3 Восстановление](references/30-restore.md) |
| Сайт восстановлен, приёмка не пройдена | сайт открывается на временном адресе, внешняя проверка не проводилась | [Ф4 Приёмка](references/40-acceptance.md) |
| Приёмка пройдена, домен не переключён | все проверки зелёные, DNS ещё смотрит на старый хостинг | [Ф5 Переключение](references/50-cutover.md) |
| Домен переключён, эксплуатация не настроена | сайт работает на VPS, бэкапов и сторожа ещё нет | [Ф6 Эксплуатация](references/60-operations.md) |
| Эксплуатация настроена, разбор не проведён | всё работает, грабли и адаптер этого случая не зафиксированы | [Ф7 Ретро](references/70-retro.md) |

## Карта фаз

1. [Ф0 Триаж](references/00-triage.md) — определить уровень заражения, зафиксировать точку отката.
2. [Ф1 Архив](references/10-archive.md) — получить снимок, доказать его чистоту.
3. [Ф2 Стек](references/20-stack.md) — поднять изолированное ядро.
4. [Ф3 Восстановление](references/30-restore.md) — развернуть сайт в ядро идемпотентно.
5. [Ф4 Приёмка](references/40-acceptance.md) — доказать работоспособность тремя источниками.
6. [Ф5 Переключение](references/50-cutover.md) — переключить домен без потери неприкосновенных записей.
7. [Ф6 Эксплуатация](references/60-operations.md) — бэкапы, внешняя копия, сторож.
8. [Ф7 Ретро](references/70-retro.md) — зафиксировать грабли и версию.

## Правила, действующие всегда

- Молчаливый отказ запрещён: рендер, линтер и стенд обязаны называть, чего не
  хватает, а не подставлять пустое значение.
- Зелёная проверка без взгляда глазами не приёмка: коды ответов и статусы
  контейнеров не заменяют сравнение тел ответов и чтение логов.
- Проверка без доказанного отрицательного результата ничего не гарантирует:
  сигнатурный скан, который никогда никого не ловил на этом стенде, не
  доказательство чистоты.
- Секреты никуда не пишутся: ни в репозиторий, ни в отчёт о самопроверке,
  ни в лог. Место для паролей одно: файл окружения с правами `600` на сервере.

Термины конвейера используются строго по [словарю](references/glossary.md),
